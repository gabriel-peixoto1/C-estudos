obs.1: O for funciona da seguinte forma: 
for(i = 0; i <= 6; i = i + 1) {}, esse último passo i++ é o que a 
função deve fazer após terminar o loop do colchete. 

Então, quando temos: 

for(i = 0; i < 6; i = i + 1) { 
        for(j = 0; j < 6; j = j + 1){ }}

estamos, basicamente, dizendo que o for j será concluído completamente
até o final, e só depois i irá virar i = i + 1, e aí ele deverá 
fazer o j todo de novo, com i = i + 1.
