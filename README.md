# C-estudos
Resumos, exercícios e provas em C. 

Durante o primeiro semestre de 2026, fiz a matéria "Programação e Desenvolvimento de Software I", oferecida pelo Departamento de Ciência da Computação da UFMG. Nessa matéria, a linguagem de programação é C. A matéria se mostrou complicada inicialmente, considerando que é uma linguagem mais rígida em relação Às linguagens que eu já tinha tido contato (Python e R). No entanto, com foco e curiosidade, consegui resultados muito satisfatórios durante o curso.  

Nesse repositório, você encontrará minhas anotações pessoais e processo de aprendizado. Pastas: 
- "Aulas": Anotações das aulas ministradas pelo excelente professor @pedroolmo.
- "Praticas": Exercícios organizados por assunto.
- "Provas": Provas antigas feitas para estudo.
